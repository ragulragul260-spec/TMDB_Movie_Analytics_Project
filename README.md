🎬 Reel Insights: An End-to-End Exploratory Data Analysis of the Global Movie Industry (TMDB)


📌 Project Overview
This project analyzes TMDB movie data using SQL, Python (Pandas), Data Visualization, and Streamlit.

The project covers:

Data Cleaning
Relational Database Design
SQL Analysis
Pandas Analysis
Data Visualization
Streamlit Dashboard Development

Python

NumPy

Matplotlib
Seaborn

📊 Top 5 Insights
Adventure movies generate the highest average revenue.
War genre has the highest average audience rating.
Avatar is the highest-grossing movie in the dataset.
Samuel L. Jackson appears in the most movies.
Movie revenue generally increases with budget.



💡 Recommendations
Focus investments on high-performing genres.
Improve audience engagement strategies.
Analyze successful blockbuster franchises.
Optimize movie budgets for better ROI.
Use data-driven casting decisions.
